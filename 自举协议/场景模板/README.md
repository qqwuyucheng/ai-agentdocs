# 场景模板库 · 使用说明

本目录是「自举协议」的场景扩展包。核心协议 [AGENTS.md](../AGENTS.md) 解决的是**规则怎么长期生长**；本目录解决的是**不同开发阶段该按什么流程干活**。

## 1. 怎么用

1. 按场景挑模板（见下表），复制到目标项目根目录并改名为 `AGENTS.md`。
2. 若目标项目已有 `AGENTS.md`，**不要覆盖**：把模板第 2～4 节（硬性规则 / 标准流程 / 交付前自检）合并进去，保留对方原有内容。
3. 始终把核心协议第 0 节的「维护协议」置于文件顶部，优先级最高。
4. 一个项目通常只需要 1 份主模板；跨阶段时用「叠加」而不是「替换」——新场景的规则追加到对应章节。

## 3. 通用约定（所有模板共享）

- **完成定义（DoD）优先于进度**：每份模板都写了「什么算完成」，达不到就不算交付。
- **自检命令只写一处**：统一放在「交付前自检」章节，不散落到各处。
- **不确定先问**：任何模板里出现「拿不准」的情况，默认动作是问用户，而不是猜。
- **规则去重**：新增规则前先检索，同类合并、失效删除，禁止重复追加。

## 4. 场景组合建议

- 从 0 做 Agent 产品：`01 → 03 → 07 → 08 → 09`
- 接手维护老系统：`02 → 05 → 06`
- 多 Agent 并行开发：`04` 常驻，其余按需叠加
- 任何场景都建议保留 `09` 与 `10` 作为基线
